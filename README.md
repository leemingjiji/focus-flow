# Focus Flow 專注循環

GitHub Pages 靜態網站。

## 發布
1. 建立 **Public** repository `focus-flow`。
2. 將此資料夾內 **index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png** 上傳到儲存庫根目錄。
3. Repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 開啟 `https://YOUR_USERNAME.github.io/focus-flow/`。

## 注意
- 任務資料儲存在瀏覽器 localStorage，不會跨裝置同步。
- iOS 背景執行可能暫停通知，但回到網頁會校正計時。
- 請不要依賴瀏覽器背景提示當作唯一提醒。
